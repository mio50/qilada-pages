# قِلادة — GitHub Pages showcase

واجهة عرض ثابتة عامة لمتجر قِلادة، منفصلة عن تطبيق المتجر الكامل.

HTML/CSS/JavaScript خالص؛ لا توجد مفاتيح API أو قاعدة بيانات أو خادم خلفي. المحتوى والأسعار والمخزون أمثلة للعرض فقط. تحفظ السلة والمفضلة محليًا في متصفح الزائر للمعاينة ولا ترسل أي معلومات؛ زر إتمام الشراء معطل عمدًا.

لا تضعوا أسرارًا أو بيانات عملاء في هذا المستودع العام. صفحة النشر الأساسية هي `index.html` في الفرع `main`.
